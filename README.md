## The work behind the title

I'm a frontend engineer in Lagos. Over the last three years I've shipped the kind of software most portfolios only mock up: a two-sided marketplace where I was the only frontend engineer, community and solar-energy apps that live on the App Store and Google Play, and internal tools at Tolaram that turn manual business processes into web apps.

I care about the unglamorous parts — payment flows that survive every edge case, chat that stays end-to-end encrypted while push notifications still arrive, a Play Store compliance migration nobody notices because nothing broke. When the platform needs it I go below JavaScript: native Kotlin and Swift modules, Gradle and the NDK. The goal is the same everywhere — interfaces that feel fast, and code the next engineer can pick up.
